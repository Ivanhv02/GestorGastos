# GestorGastos

Aplicación de consola desarrollada en Java como proyecto personal para practicar programación y reforzar los conocimientos adquiridos en el Grado Superior de Desarrollo de Aplicaciones Multiplataforma (DAM).

## Funcionalidades

- Registro de gastos personales.
- Consulta de los gastos registrados.
- Cálculo del total gastado.
- Organización de los gastos por categorías.
- Validación de datos introducidos por el usuario.

## Tecnologías utilizadas

- Java
- IntelliJ IDEA
- Scanner para la entrada de datos por consola.

## Cómo ejecutar el proyecto

1. Clona o descarga este repositorio.
2. Abre el proyecto en IntelliJ IDEA.
3. Comprueba que tienes un JDK instalado.
4. Ejecuta el método `main` de la clase `Main`.

## Objetivo

Proyecto de aprendizaje orientado a practicar programación orientada a objetos, colecciones, estructuras de control y gestión de datos.
